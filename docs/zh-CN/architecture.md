# 架构

## 系统架构概述

本文档介绍管理系统的整体架构设计和技术栈。

## 技术栈

### 前端框架
- **Vue 3** - 渐进式 JavaScript 框架
- **Vue Router** - 官方路由管理器
- **Composition API** - Vue 3 的组合式 API

### 构建工具
- **Vite**

### 代码规范
- **ESLint** - JavaScript 代码检查工具

## 项目结构

```
src/
├── apis/              # API 接口
│   ├── admin-api/    # 管理后台 API
│   └── request/      # 请求封装
├── components/        # 组件
│   └── admin/        # 管理后台组件
├── views/             # 页面视图
│   └── admin/         # 管理后台页面
├── router/            # 路由配置
├── plugins/           # 插件
├── utils/             # 工具函数
└── assets/            # 静态资源
```

## 核心模块

### API 层
- 统一的请求客户端封装
- 请求/响应拦截器
- 错误处理机制

### 用户登录认证
- 基于 cookie 认证

### 权限系统
- 页面权限 （菜单路由）
- 按钮权限 （增删改查等 动作）

### 菜单
- 动态菜单，从后台获取菜单数据。用户获取自己有权限的菜单。

## 设计原则

- **组件化**：可复用的组件设计
- **模块化**：清晰的模块划分
- **可维护性**：代码结构清晰，易于维护
- **可扩展性**：便于功能扩展
